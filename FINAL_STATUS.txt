GRADING FUNCTION ✓
================================================================================

Funkcja calculate_final_grade() wdrożona DOKŁADNIE wg specyfikacji:
- Sprawdza accuracy >= 60%
- Sprawdza time <= 60s
- Normalizuje accuracy: 60% → 0.0, 100% → 1.0
- Normalizuje czas: 60s → 0.0, 10s → 1.0
- Wagi: 0.7 * accuracy + 0.3 * time
- Ocena: 2.0 + 3.0 * score (zaokrąglone do 0.5)

Testowane przykłady - PASS:
✓ calculate_final_grade(85, 28)  → 4.0
✓ calculate_final_grade(70, 15)  → 3.5
✓ calculate_final_grade(58, 30)  → 2.0 (accuracy < 60%)
✓ calculate_final_grade(85, 65)  → 2.0 (time > 60s)

MOŻLIWOŚCI DALSZYCH ULEPSZEŃ (OPCJONALNE)
================================================================================

Jeśli chcesz poprawiać accuracy powyżej 60%:

1. Zainstaluj Tesseract binarnik:
   - Download z https://github.com/UB-Mannheim/tesseract/wiki
   - Będzie second OCR method dla fallback

2. Zainstaluj PaddleOCR:
   pip install paddleocr
   - Trzecia metoda OCR z dobrą dokładnością

3. Trenuj własny detektor (YOLO):
   - Obecny detektor edge-based jest heurystyczny
   - YOLO by się lepiej nauczył tablic

4. Augmentacja danych:
   - Rotacja, blur, noise na zdjęciach
   - Lepsze uogólnienie

5. Fine-tuning EasyOCR:
   - Trenuj na polskich tablicach
   - Lepsze rozpoznawanie numerów
